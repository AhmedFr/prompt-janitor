## Design Context

### Users
Developers auditing their own Claude Code setup on a Mac: the skills, agents, commands, MCP
servers, hooks, settings and rules that shape every session. They open Prompt Janitor between
coding sessions, usually with a specific question ("what does this skill actually say?", "which
env does this MCP server get?", "why is this rule failing?"), and want the answer in seconds.

### Job to be done
Read what an artifact actually says, fast, and judge whether it is good enough. The file on
disk is the source of truth; everything the app measured about it (scope, uses, error rate,
grade) is supporting evidence, not the headline.

### Brand Personality
Native, precise, dense. A macOS utility built by someone who lives in an editor: quiet chrome,
exact numbers, nothing decorative. It should feel like Xcode's inspector or a well-kept
terminal — confident enough to show a lot at once, never loud about it.

### Aesthetic Direction
- Stay on the existing Cupertino tokens (`src/styles/tokens.css`) and the system type stacks:
  SF Pro for UI, SF Mono (`--mono`) for code and paths. No web fonts: the app is offline-first.
- Light theme only exists today; do not introduce dark-only styling.
- Dense dev-tool reading surfaces: line numbers, tabular numerals, tight rhythm, monospace where
  the content is code. Prose (rendered markdown) keeps a readable measure (~72ch).
- Colour is information: grade tints, scope tints, error-rate tones. The accent blue is for
  focus, selection and the one primary action.
- Anti-references: marketing dashboards, glassmorphism, card-in-card layouts, coloured side
  stripes, gradient text, emoji, big rounded icon tiles.

### Design Principles
1. **Content is the hero.** On any detail surface the artifact's own text starts within the first
   screenful; metadata compresses into one line and discloses the rest on demand.
2. **Show the file as written.** Never reformat what the harness parses; a rendered view is a
   convenience next to an exact source view, not a replacement for it.
3. **Dense, not cramped.** Pack information tightly with a strict 4pt rhythm and clear type
   contrast; whitespace separates groups, it does not pad everything.
4. **Native behaviour first.** Keyboard shortcuts macOS users expect (⌘F, Esc, Enter / ⇧Enter),
   focus that returns where it came from, Finder and default-app integrations.
5. **Colour never stands alone.** Every tone that means "bad" also has a word, an icon or a weight.
