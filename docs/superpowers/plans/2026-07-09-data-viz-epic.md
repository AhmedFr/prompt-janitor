# Data-viz epic Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an Overview heatmap, a data-driven file-detail radar (5 quality dimensions), and a new Analytics page with real grade/trend/fix metrics.

**Architecture:** Rust tags every built-in rule with one of five dimensions, persists each issue's dimension, and aggregates per-file dimension scores; a durable `fix_events` table backs the "issues fixed" metric; a `get_analytics(range)` command shapes the Analytics screen. React renders charts with **Recharts** (themed to the app's grade/color tokens) plus a CSS-grid heatmap mosaic.

**Tech Stack:** Rust (rusqlite, git2), React 18 + TypeScript, Recharts, Vite, Vitest + Testing Library, Storybook, plain CSS tokens.

## Global Constraints

- Package manager **pnpm** (`pnpm test`, `pnpm typecheck`, `pnpm lint`). Rust: `cd src-tauri && cargo test`.
- Bindings `src/lib/bindings.ts` are GENERATED by the `export_typescript_bindings` test in `src-tauri/src/ipc.rs` (run `cargo test`); never hand-edit. Import IPC from `@/lib/ipc`.
- Component convention: one folder per component (`Name.tsx`, `Name.types.ts`, optional `Name.constants.ts(x)`, `Name.css`, `Name.test.tsx`, `Name.stories.tsx`, `index.ts`).
- RTL does NOT auto-clean between tests — every test file uses `afterEach(cleanup)`.
- Charts use **Recharts**, themed with tokens (`--grade-a..f`, `--blue`, `--text-*`, `--red`, `--green`). No Tailwind.

- [ ] **Step 3: Implement helper**

`heatmap.util.ts`:
```ts
import type { FileRow, Grade } from "@/lib/ipc";
import type { HeatLegend, HeatSquare } from "./Heatmap.types";

const GRADES: Grade[] = ["A", "B", "C", "D", "F"];

export function bucketFiles(files: FileRow[]): { squares: HeatSquare[]; legend: HeatLegend[] } {
  const squares = files
    .map((f) => ({ id: f.id, name: f.name, grade: f.grade, score: f.score }))
    .sort((a, b) => b.score - a.score);
  const counts = new Map<Grade, number>(GRADES.map((g) => [g, 0]));
  for (const s of squares) counts.set(s.grade, (counts.get(s.grade) ?? 0) + 1);
  const legend = GRADES.map((grade) => ({ grade, count: counts.get(grade) ?? 0 }));
  return { squares, legend };
}
```

```tsx
  const chartData = data.map((d) => ({ dim: SHORT[d.dimension] ?? d.dimension, score: d.score }));
  return (
    <div style={{ width: "100%", height: size }} role="img" aria-label="Dimension scorecard">
      <ResponsiveContainer>
        <RC data={chartData} outerRadius="72%">
          <PolarGrid stroke="var(--sep-strong)" />
          <PolarAngleAxis dataKey="dim" tick={{ fill: "var(--text-2)", fontSize: 11 }} />
          <PolarRadiusAxis domain={[0, 100]} tick={false} axisLine={false} />
          <Radar dataKey="score" stroke={color} fill={color} fillOpacity={0.35} isAnimationActive />
        </RC>
      </ResponsiveContainer>
    </div>
  );
}
```
