# Menu-bar panel — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Every task also follows the project skill `shipping-a-feature`.

**Goal:** A floating panel under the menu-bar icon showing verdict, top-3 fixes, usage signals and Scan/Open/Quit; left-click toggles it, right-click keeps the menu; the app becomes menu-bar-first when the main window is closed.

**Architecture:** A second hidden Tauri webview window (`panel`) positioned from the tray click `rect`; `panel.rs`/`window_policy.rs` own window behaviour; one composed read model `get_panel_snapshot`; `open_main(route, target)` bridges panel clicks into the main window via a `navigate` event; the React entry branches on `?window=panel` to render `src/screens/Panel`.

**Tech Stack:** Tauri 2 (`tray-icon`, `WebviewWindowBuilder`, `ActivationPolicy`), rusqlite, tauri-specta bindings, React 18 + TS, Vitest/Testing Library/vitest-axe, Storybook 8.

**Spec:** `docs/superpowers/specs/2026-08-23-menu-bar-panel-design.md`

## Global Constraints

- Rust gates: `cd src-tauri && cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test`. Frontend gates: `pnpm lint && pnpm typecheck && pnpm test && pnpm storybook:build`.
- IPC types use `i32`/`u32`/`f64`/`String`/`bool` (+ `Option`/`Vec`/existing enums); `src/lib/bindings.ts` regenerated by `cargo test`, committed, never hand-edited; new types re-exported from `src/lib/ipc.ts`.
- Harness modules import `crate::harness::model` only, never `claude_code::*`.
- macOS-only APIs (`set_activation_policy`) behind `#[cfg(target_os = "macos")]` with no-op fallbacks so Linux CI builds.
- Component folders: `index.ts`, `<Name>.tsx`, `<Name>.types.ts`, optional `.constants.ts`, test, story; layout-only screens, logic in hooks/utils with tests; CSS tokens only (`src/styles/tokens.css`), no Tailwind.
- Panel window: 360 × 480 logical px, `decorations(false)`, `transparent(true)`, `always_on_top(true)`, `resizable(false)`, `skip_taskbar(true)`, starts hidden; `"macOSPrivateApi": true` in `tauri.conf.json`.
- Every PR updates `docs/status/data.json` + `pnpm status`; PR 1 adds an owner action "verify panel positioning/transparency on a real Mac".

## PR 1 — window plumbing + snapshot (issue #141)

### Task 1: `panel_snapshot` read model

**Files:** Create `src-tauri/src/panel_query.rs`; modify `src-tauri/src/lib.rs` (`mod panel_query;`), `src-tauri/src/commands.rs` (`get_panel_snapshot`), `src-tauri/src/ipc.rs` (register command + export types), `src/lib/ipc.ts` (re-export `PanelSnapshot`, `PanelFix`).

**Interfaces (Produces):**
```rust
#[derive(Serialize, Type)] pub struct PanelFix { pub file_id: String, pub name: String, pub project_name: String, pub grade: Grade, pub issue_count: u32 }
#[derive(Serialize, Type)] pub struct PanelSnapshot { pub has_data: bool, pub overall_grade: Grade, pub overall_score: u32, pub delta: i32, pub last_scan_at: Option<String>, pub top_fixes: Vec<PanelFix>, pub never_used_skills: u32, pub mcp_erroring: u32, pub sessions_today: u32 }
pub fn panel_snapshot(conn: &Connection, now: OffsetDateTime) -> rusqlite::Result<PanelSnapshot>
#[tauri::command] #[specta::specta] pub fn get_panel_snapshot(db: State<AppDb>) -> Result<PanelSnapshot, String>
```
Rules: `overall_*`/`delta`/`has_data` reuse `query::get_overview` (`trend_delta`); `last_scan_at` = max over `harness_projects.last_scan_at`-equivalent `harnesses.last_scan_at` and `scans.finished_at`; `top_fixes` = files ordered by grade F→A then `issue_count` desc, limit 3, `name` = file basename, `project_name` via `projects`; `never_used_skills` = `artifacts WHERE kind='skill'` with no `usage_stats` row; `mcp_erroring` = `artifacts kind='mcp_server'` joined to `usage_stats` with `error_rate >= 0.25`; `sessions_today` = sessions whose `started_at` ≥ UTC midnight of `now` (same day arithmetic as `harness_query::window_calendar_days`).

### Task 2: window policy + panel window + tray click model

**Files:** Create `src-tauri/src/window_policy.rs`, `src-tauri/src/panel.rs`; modify `src-tauri/src/tray.rs`, `src-tauri/src/lib.rs` (setup: `panel::create(app)?`; `on_window_event` for `main` CloseRequested), `src-tauri/src/commands.rs` (`open_main`, `quit`), `src-tauri/src/ipc.rs`, `src-tauri/tauri.conf.json` (`"macOSPrivateApi": true` under `app`), `src/lib/ipc.ts`.

**Interfaces (Produces):**
```rust
// window_policy.rs
pub fn show_main(app: &AppHandle)   // show + set_focus + Regular (macOS)
pub fn hide_main(app: &AppHandle)   // hide + Accessory (macOS)
// panel.rs
pub const PANEL_LABEL: &str = "panel"; pub const PANEL_SIZE: (f64, f64) = (360.0, 480.0); pub const PANEL_GAP: f64 = 6.0; pub const PANEL_MARGIN: f64 = 8.0;
#[derive(Clone, Copy, Debug, PartialEq)] pub struct Rect { pub x: f64, pub y: f64, pub w: f64, pub h: f64 }
pub fn position_under(icon: Rect, work_area: Rect, size: (f64, f64)) -> (f64, f64)  // pure
pub fn create(app: &App) -> tauri::Result<()>
pub fn toggle(app: &AppHandle, icon: Rect)   // hide if visible else position + show + focus
// commands.rs
#[tauri::command] pub fn open_main(app: AppHandle, route: String, target: Option<String>)  // show_main; app.emit_to("main", "navigate", NavigateEvent{route,target}); hide panel
#[tauri::command] pub fn quit(app: AppHandle)
```
`toggle` converts the tray `rect` (physical `Position`/`Size`) to logical via the monitor under the icon (`app.monitor_from_point` or `primary_monitor`) and its `work_area` when available (fallback: monitor size). Blur: `on_window_event` `Focused(false)` on `panel` → `hide()`.
