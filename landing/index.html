FAQ

Good questions.

Which files does it scan?

The prompt & instruction files agents read — CLAUDE.md, AGENTS.md, .cursorrules, .github/copilot-instructions.md and friends.

Is my data private?

Yes. Everything runs locally on your Mac. The only network call is to the AI provider you choose for the paid features — made with your own key, nowhere else.

Do I need an API key?

Only for the Pro AI features. Scanning, grading, cited issues, the scheduler and pattern rules are free and fully offline.

Will it change my files?

Only when you click Apply — and it snapshots a backup first (undo anytime), with an optional commit on a dedicated prompt-janitor/fix-* git branch.

How does the license work?

A one-time, offline license key. It's verified on your machine with public-key cryptography — no account, no server, no phone-home.
