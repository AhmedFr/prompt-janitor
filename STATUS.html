    The provider API key is written to the `settings` table in plaintext today, so anyone with read access to the app's SQLite file has it.   2. Decide phase 2 scope: evidence-backed findings + diff apply vision call

    With usage evidence now landing, decide whether phase 2 should turn it into evidence-backed findings (e.g. 'unused skill', 'MCP server never called') and/or let fixes be diff-applied directly from the Setup screen.

  3. Version number for launch vision call

  4. Auto-update: in v1 or after? vision call

    Tauri's updater needs its own signing keypair and an update manifest endpoint. Recommendation: ship v1 without it, add in v1.1 — early users will re-download.
